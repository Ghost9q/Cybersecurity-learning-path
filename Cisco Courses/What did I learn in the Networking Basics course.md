What did I learn in the Networking Basics course

This file summarizes what I learned from the Cisco Networking Academy Networking Basics course.  
It is part of my journey in the Junior Cybersecurity Analyst Path.

1. Introduction to Networking
- A network is a collection of devices connected to share data and resources.  
- Types: LAN, WAN, WLAN, MAN  
- Importance: communication, resource sharing, scalability, internet access

2. Network Components
- End devices: PCs, smartphones, servers, IoT  
- Intermediary devices: routers, switches, firewalls, access points  
- Media: copper cables, fiber optics, wireless signals  
- Protocols: TCP/IP, HTTP, FTP, DNS

3. Data Transmission
- All data is transmitted as 1s and 0s  
- Bandwidth = maximum capacity, throughput = actual speed  
- Latency = travel time of data  
- Data is divided into packets

4. OSI and TCP/IP Models
- OSI: Physical, Data Link, Network, Transport, Session, Presentation, Application  
- TCP/IP: Network Access, Internet, Transport, Application  
- Encapsulation = adding headers, De-encapsulation = removing headers

5. IP Addressing
- IPv4: 32-bit, written as 192.168.0.1  
- IPv6: 128-bit, written as 2001:0db8::1  
- Subnetting: dividing networks into smaller parts  
- Private IP ranges: 192.168.x.x, 10.x.x.x, 172.16-31.x.x  
- Default gateway = router interface to outside networks

6. Common Protocols
- HTTP/HTTPS = web browsing  
- FTP/SFTP = file transfer  
- DNS = resolves names to IPs  
- DHCP = assigns IPs automatically  
- ICMP = testing and error reporting (ping)  
- SMTP/IMAP/POP3 = email

7. Network Devices
- Switch = forwards frames using MAC addresses  
- Router = forwards packets using IP addresses  
- Access Point = provides wireless connection  
- Firewall = controls network traffic

8. Wireless Networking
- Wi-Fi standards: 802.11a/b/g/n/ac/ax  
- Security: WEP, WPA, WPA2, WPA3  
- SSID = network name  
- 2.4 GHz = longer range, slower  
- 5 GHz = faster, shorter range

9. Network Security Basics
- Threats: malware, phishing, DoS, MITM  
- Practices: strong passwords, firewall, updates, segmentation

10. Basic Configuration
- Show commands display interface and routing info  
- DHCP can assign IPs automatically  
- Static IP = manual, Dynamic IP = automatic

11. Troubleshooting Tools
- ping = test connectivity  
- tracert/traceroute = show packet path  
- ipconfig/ifconfig = display IP info  
- netstat = show active connections

12. Key Takeaways
- Networking is about connectivity, communication, security  
- Protocols, addressing, and devices are core concepts  
- CLI and Packet Tracer practice is essential
